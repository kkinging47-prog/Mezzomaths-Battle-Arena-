# Puzzle Escape

Home → Games & live battles → Puzzle Escape; also in More activities. A solo point-and-click escape-house game using the existing class/curriculum question bank.

Each of five rooms requires searching the desk, copying a wall clue, answering one unique maths question at the console and solving an interactive lock. The locks are a symbol sequence, neighbour-toggle circuit, 2×3 sliding mosaic, subset-weight balance and four-digit vault code. The first four rooms add numbered seals to the notebook; enter them in room order, preserving zeroes, in the final vault. Puzzle configurations derive from the selected question IDs and adventure level. Generated circuits and mosaics are solvable; hints compute a valid next move.

Five adventures: Lost Library, Clockwork Workshop, Crystal Observatory, Hidden Vault, Mezzo Master Escape. Symbol sequences increase from three to five and circuits from three to five lamps. Active exploration time falls from 12 minutes to 8. Questions, reports and pause stop the clock. Escape, window blur and tab hiding pause. Correct maths adds one hint token, capped at five; two tokens are available initially. An unchanged hint is charged once. Wrong maths still permits solving the room; maths is reviewed at the unlocked door. All five rooms plus at least 3/5 maths correct unlock the next adventure. Three stars require at least 4/5 correct and at most one hint; other qualifying escapes receive two stars. Escaping with fewer than three correct earns one star but no unlock.

All room objects, puzzle pieces and actions are native buttons/inputs with keyboard access, labelled state and visible focus. The slide puzzle enables only tiles adjacent to the gap. SVG scenes use room-specific palettes and code-native art; reduced motion removes torch animation. No new dependencies or image services.

Class setup supports Grade 1–9 and SHS 1–3 with GES, Cambridge and Pearson Edexcel selections. All topics includes unassigned questions. A real run requires five usable unique MCQs; unavailable content does not silently fall back to demo maths. The labelled Level 1 demo uses sample arithmetic and never saves or unlocks anything.

Persistence reuses the existing account-scoped results store under mode puzzle_escape and separate cache mezzo_puzzle_escape_v1. Saved metadata contains room outcomes, answers, hints, stars and unlock progress. Offline receipts retain stable IDs; account changes close the overlay and reset owner state. No schema or RLS change. These are practice game results, not server-validated assessment scores.
